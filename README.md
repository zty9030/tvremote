# TV Remote

A lightweight web-based remote controller for rooted Android TVs.

## Features

- HTTP Server
- Web UI
- Android ARMv7
- Root command execution (coming soon)

## Build

```bash
make run
```

## Android

Build locally:
```bash
make android
```

Download pre-built Android binary from [releases](https://github.com/zty9030/tvremote/releases).
